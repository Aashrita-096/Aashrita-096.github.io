# Aashrita Yarlagadda — Cybersecurity Portfolio

A responsive, single-page portfolio website with a dark navy / muted green cybersecurity visual theme.

## Run locally

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Review every section and update any detail that has changed.

No build step or package installation is required.

## Files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive visual theme
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages

1. Sign in to GitHub and open `https://github.com/Aashrita-096`.
2. Create a new public repository named `Aashrita-096.github.io`.
3. Upload the contents of this folder (not the outer ZIP).
4. Commit the files to the `main` branch.
5. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After GitHub Pages finishes publishing, the site should be available at `https://aashrita-096.github.io/`.

If a repository with that name already exists, use its existing Pages configuration or choose another repository and enable Pages in Settings.
